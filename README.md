## 🚀 कैसे चलाएं या देखें (How to View):

### 1. सीधे ब्राउज़र में खोलें:
`index.html` फाइल पर डबल क्लिक करें — यह किसी भी ब्राउज़र (Chrome, Edge, Safari) में तुरंत खुल जाएगी।

### 2. लोकल सर्वर से चलाने के लिए:
यदि आप Node.js के साथ लोकल टेस्ट करना चाहते हैं:
```bash
npx serve
```
या
```bash
npx http-server
```
